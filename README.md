# 提案フィードバック管理ツール
Proposal Feedback Manager

クライアントからの要望・修整に対して、複数のバリエーション提案を生成・比較・PDFで出力できるツールです。

## 🚀 今すぐ使う

👉 **公開ページ：** https://yu-ma0730.github.io/Proposal-Feedback-Manager/

## 概要

フリーランスが企業に提案を出した後、クライアントから「修整してほしい」という要望が来た場合に使用します。

**流れ：**
1. 提案査定ツールで提案を評価 → **案件ID をコピー**
2. このツールで案件ID と提案文をペースト
3. クライアントからの要望を入力
4. AI が 3～5個のバリエーション（修整案）を自動生成
5. スライド形式で比較検討
6. **PDF で出力してクライアントに提出**
7. **案件IDで履歴が自動保存される**

## 🚀 クイックスタート

### 準備するもの
- Claude API キー
- 提案査定ツールで生成した「案件ID」
- 提案内容のテキスト

### 手順

**ステップ1：APIキー設定**
```
Claude API キー（sk-ant-... の形式）を入力
↓
自動保存されます
```

**ステップ2：案件情報を入力**
```
【案件ID】
提案査定ツールで表示される「CASE-...」をコピペ

【提案内容】
提案査定ツールから「📋 提案内容をコピー」ボタンで
コピーした内容をペースト
```

**ステップ3：クライアント要望を入力**
```
【クライアント要望】必須
例：
- 「冒頭をもっと簡潔に」
- 「技術スキルをより強調してほしい」
- 「YY企業に特化した内容に」

【補足情報】任意
例：
- 「クライアントの業界：SaaS」
- 「ターゲット企業：XX社」
```

**ステップ4：バリエーション確認**
```
「生成する」ボタン
  ↓
AI が 3～5個の修整案を生成
  ↓
スライド形式で表示
  ├─ 各スライド：
  │  ├─ アプローチの説明
  │  ├─ 重要ポイント
  │  ├─ 修整後の提案
  │  └─ 第三者評価
  ↓
好きなパターンをクリック選択
```

**ステップ5：PDF出力**
```
「📄 PDFをダウンロード」ボタン
  ↓
全バリエーションを含むPDFが生成
  ↓
クライアントにメール送付
```

**ステップ6：完了**
```
「✓ 完了」ボタン
  ↓
案件ID + 選択内容が自動保存
  ↓
次の案件に移行可能
```

## 💾 データ管理

### 自動保存される情報
各フィードバックは案件IDごとに自動保存されます：

```
案件ID: CASE-1729620000000-ABX1Y
├─ 提案内容
├─ クライアント要望
├─ 選択されたバリエーション
└─ 実行日時
```

### ローカルストレージ
- **APIキー**：初回入力後、自動保存
- **フィードバック履歴**：案件ごとに自動保存

## 📋 各バリエーションに含まれる情報

### 📌 アプローチ
このバリエーションの修整方針を説明
```
例：「簡潔重視型」
実績を前面に出し、余分な表現を削減した提案
```

### ⭐ 重要ポイント
このアプローチで重視した要素（箇条書き）
```
例：
- 3つの実績を最初に提示
- テクニカルスキルを定量的に表現
- クライアント業界知識を明示
```

### 📝 修整後の提案
実際の修整内容（実用的な提案文）
```
クライアントにそのまま提出可能な内容
```

### 🔍 第三者評価
客観的な評価・メリット・デメリット
```
例：
✓ メリット：簡潔で読みやすい
✗ デメリット：詳細が削られる可能性
→ 推奨度：★★★★☆
```

## ⚙️ 技術仕様

- **言語**：HTML5 + Vanilla JavaScript
- **API**：Claude API（Opus 5.5 モデル）
- **PDF 生成**：html2pdf.js
- **データ保存**：LocalStorage（APIキー・履歴）
- **案件ID 管理**：タイムスタンプ + ランダム5文字

## 🔐 セキュリティ・プライバシー

### APIキーについて
- ✅ このページ内のみで使用
- ✅ 外部サーバーには送信されない
- ✅ ブラウザの LocalStorage に保存
- ⚠️ 定期的にリセット推奨

### データについて
- 提案内容とクライアント要望は Claude API に送信されます
- 機密情報が含まれる場合は注意してください
- LocalStorage に保存されたデータはあなたのみアクセス可能

## 📞 トラブルシューティング

### Q: 「APIエラー」と表示される
**A:** 
- APIキーが正しいか確認
- ネットワーク接続を確認
- キーの有効期限を確認

### Q: PDFが生成されない
**A:**
- ブラウザの設定でポップアップをブロックしていないか確認
- JavaScript が有効になっているか確認

### Q: データが消えた
**A:**
- ブラウザのキャッシュをクリアしていないか確認
- シークレットモードで開いていないか確認
- LocalStorage を確認してください

## 💡 使用例

### ケース1：複数クライアント対応
```
案件A（クライアントX）
  ↓ CASE-1729620000000-ABX1Y
  → バリエーション選択
  → PDF送付
  ↓
案件B（クライアントY）
  ↓ CASE-1729620100000-CDX2Z
  → バリエーション選択
  → PDF送付
  ↓
すべて案件IDで履歴管理
```

### ケース2：修整回数が多い場合
```
初回フィードバック（案件ID: CASE-...）
  ↓ バリエーション選択 → PDF送付
  ↓
2回目フィードバック（同じ案件ID: CASE-...）
  ↓ 新たにバリエーション生成 → PDF送付
  ↓
案件IDで全修整履歴が管理される
```
