# 提案フィードバック管理ツール
Proposal Feedback Manager

クライアントからの要望・修整に対して、複数のバリエーション提案を生成・比較・PDFで出力できるツールです。

## 概要

フリーランスが企業に提案を出した後、クライアントから「修整してほしい」という要望が来た場合に使用します。

**流れ：**
1. 提案査定ツールで生成した提案文を「コピー」
2. このツールに貼り付け
3. クライアントからの要望を入力
4. AI が 3～5個のバリエーション（修整案）を自動生成
5. スライド形式で比較検討
6. PDF で出力してクライアントに提出

## 特徴

✅ **複数アプローチの自動生成**
- Claude AI が クライアント要望に基づいて 3～5 個の修整案を生成
- 異なる視点からの提案が可能

✅ **詳細な分析情報**
- 各バリエーションに以下を含む：
  - ネーミング（アプローチ説明）
  - 重要ポイント
  - 修整後の提案文
  - 第三者としての客観的評価

✅ **スライド形式での比較**
- 複数のバリエーションをスライドで順番に比較
- クリックで直接選択も可能

✅ **PDF 出力機能**
- 全バリエーションを含む PDF を自動生成
- クライアント提出用に最適化

✅ **自然な日本語対応**
- 提案文からクライアント評価まで、すべて自然な日本語で処理

## 使い方

### ステップ 1：APIキー設定
Claude API キーを入力します。
- キーはこのページ内でのみ使用され、外部には送信されません
- 初回入力後、自動で保存されます

### ステップ 2：提案内容を貼り付け
提案査定ツールから「📋 フィードバック管理ツールにコピー」ボタンで査定結果をコピーして貼り付けます。
または、任意の提案文をテキストで貼り付けることも可能です。

### ステップ 3：クライアント要望を入力
クライアントからの修整・要望を詳しく入力します。

**例：**
- 「冒頭をもっと簡潔に」
- 「技術スキルをより強調してほしい」
- 「YY企業に特化した内容に」

### ステップ 4：バリエーション確認
生成された 3～5 個のバリエーションを確認します。

各バリエーションには以下の情報が含まれます：
- **アプローチ**：このアプローチの説明
- **重要ポイント**：重視した要素（箇条書き）
- **修整後の提案**：実際の修整内容
- **第三者評価**：客観的な評価・メリット・デメリット

### ステップ 5：PDF 出力・確定
全バリエーションを含む PDF をダウンロードして、クライアントに提出します。

## 技術仕様

- **言語**：HTML5 + Vanilla JavaScript
- **API**：Claude API（Opus 5.5 モデル）
- **PDF 生成**：html2pdf.js
- **データ保存**：LocalStorage（APIキー）

## セットアップ

### 1. リポジトリをクローン
```bash
git clone https://github.com/yu-ma0730/Proposal-Feedback-Manager.git
cd Proposal-Feedback-Manager
```

### 2. GitHub Pages で公開
リポジトリの Settings → Pages で公開設定をします。

### 3. Claude API キーを取得
https://console.anthropic.com から API キーを取得します。

### 4. ツールにアクセス
`https://yu-ma0730.github.io/Proposal-Feedback-Manager/` でアクセスできます。

## 注意事項

⚠️ **APIキーの管理**
- 入力したキーはこのページ内でのみ使用されます
- ブラウザの LocalStorage に保存されます
- 定期的にキーをリセット/再生成することをお勧めします

⚠️ **プライバシー**
- クライアント要望や提案内容は Claude API に送信されます
- 機密情報が含まれる場合は注意してください
